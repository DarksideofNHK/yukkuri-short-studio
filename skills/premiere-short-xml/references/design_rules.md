## 締め（エンドカード）

黒地に引用を並べた画像のエンドカードはやめた（ユーザー「エンドカードがちょっと良くない」）。最後に説明役の締めの一言（例「それが、NHK会長の決め方だ。」）を足し、テロップ（`hold: true`）と背景・図（NHK会長編では3段の図と視聴者の家）をエンドカードの終わりまで残し、発信者表示だけを下1/3に重ねる（spec の `end_card: {"style": "hold", "sender": …}`）。締めはその動画の要点を短くまとめる。

## イラスト（chars・人物の似顔絵）

2026-09-27 ユーザー指示（実際の制作で決めた）：**顔のイラストは基本的に大きく。出てから1秒くらい顔が見えていれば、そのあとテロップを被せてよい。テロップは重ねてもいいが、あえて顔に重ねるときは意味が大事**（意味のない重ね方で顔が見えなくなるのが一番よくない）。小さい絵にテロップが乗ると何も見えなくなる。

- 顔には重ねない（重なるのは胸から下）。名札など演出の要になる小物もテロップに隠さない。隠れるときは、図を途中で下げて（v2 の until）人物を上に大きく寄せる
- 読みやすさの底上げはテロップの座布団（グレー・不透明度40％）で。暗幕（全面の帯）は使わない

- 出すのは、ナレーションがその人の話をしている拍（登場・「最悪」「できていない」・謝罪の引用・オチ）。ずっと出しっぱなしにしない
- 画面下（頭の上端 y≈1150・1.25倍）か、その行に図がないときは図の位置に大きく（2.0倍・860 から下はぼかす）。顔が注記（y≈1470）にかからないようにする
- 風刺は、表情（笑顔・汗・目をそらす・首かしげ）と出し入れのタイミング、事実に根拠のある小物（会長の名札・委員の席）、実際の発言に合わせた口パクで作る。事実でないこと（逃げる・走る・家に帰る・資料にない人物）は絵にしない
- 初めて出るところに「※イラストはイメージです」を小さく出す。素材リストの注意にも書く

## 色と動き

- 色：白 `w`（ふつう）、黄 `y`（数字・キーワード）、赤 `r`（人名・いちばん強い言葉）、ピンク `p`（聞き手）
- テロップの動き：黄・赤を含む → `pop`（65→108→100％、6フレーム）、白だけ → `rise`、聞き手 → `soft`、小さい語 → なし
- グラフ：言葉が読まれた瞬間に、棒が伸びる・線が伸びる・光る・ハンコ・揺れ
- スクショ：資料が出る → 寄る → マーカー → 赤枠 → ハンコ。1つの図に動きは3〜4つまで

## テロップの文言（掛け合い型のショート）

- 画面に出すのは要点の語だけ。セリフ全文は出さない
- 1行は9文字前後まで（104px で画面幅に収まる）。長いものは2段に分ける
- 色が変わるところで段を分ける（文字クリップは1クリップ1色）
- 振ったらすぐ答えを出す。聞き手のツッコミは短く（ピンク）

## 出典と表現

- 数字・言葉は資料に根拠があるものだけ。資料の言い回しと違う言い方をするときは、注記に原文を出す（例：ナレーション「9人以上の賛成」／条文「委員九人以上の多数による議決」）
- マーカーは資料の実際の文字に引く。ハンコは資料の言葉から取った短い語（「九人以上」など）＋ 出典と日付
- スクショ・注記には資料名・ページ・日付を出す
- 公開サンプルの画面素材は自作の絵・自作の図・e-Gov の法令条文だけ。番組映像・公式ロゴの形・報道写真・人物の公式写真そのものやトレースは使わない
- ゆっくりボイス（AquesTalk）の利用条件は用途に応じて公式サイトで確認する。非営利の個人利用と、収益化・業務利用とを区別する

## 付録：政治・選挙を扱う動画のとき

- 公職選挙法の発信者表示（142条の5）・虚偽事項の公表（235条）などを、公開時点の条文と発信内容・時期に照らして確認する。下部の発信者表示枠を置くだけで適法性を保証するものではない。
- 数字・人物の発言・風刺の根拠を一次資料と照合する。締めを視聴者の判断に委ねる構成では、投票先を指示する表現を避ける。
- BGM・効果音の規約には政治・宗教・イデオロギーに関する制作物への利用を禁じる場合がある。OpenTracks 等の配布元ごとに現行規約を確認し、不明なら提供元に確認する。過去の別案件で使えたことを許諾の根拠にしない。
