# Macでゆっくりボイスを作る

更新：2026年9月28日（公開用 v2）  
確認時の環境：AquesTalkPlayer Mac 1.0.1／Apple Silicon／macOS 26.5.2  
コマンド本体はリポジトリの `tools/yukkuri` にあり、`install.sh` で `~/.local/bin/yukkuri` に入れます。AquesTalkPlayer は利用者が[公式サイト](https://www.a-quest.com/products/aquestalkplayer.html)から別途入手し、`/Applications/AquesTalkPlayer.app` に配置してください。アプリ本体・インストーラーは同梱しません。用途に応じて公式の利用条件を確認してください。

CLI・HTTP APIも追加済みです。自動化する場合は [CLI・APIマニュアル](CLI_APIマニュアル.md) を参照してください。

## 導入後の設定例

以下は Mac 版の設定例です。利用者の環境でアプリを開き、声のプリセットと WAV 設定を確認してください。原稿の音声合成はローカルで実行します。

| 設定 | 設定例 |
|---|---|
| 初期プリセット | れいむ（AquesTalk1 / f1） |
| 話速・音量・音程 | 各100 |
| 棒読み | オン |
| WAV出力 | 48kHz・16bit・モノラル |
| リサンプリング | Sinc |
| ファイル名 | 保存時に手動指定 |

最初に短い文章を Wav Save とコマンドで生成し、WAV の形式と無音でないことを確認してください。発音や速さは試聴して調整します。

## 最初の1本を作る

1. アプリケーションにある **AquesTalkPlayer** を開きます。
2. テキスト欄に、読み上げたい文章を貼り付けます。まずは「こんにちは。ゆっくりしていってね。」で試します。
3. プリセットから **れいむ** または **まりさ** を選びます。最初は「れいむ」で試します。
4. **Play** で試聴し、読み方と速さを確認します。
5. **Wav Save** で音声を書き出します。保存先は、このフォルダ内の「音声」を使うと整理しやすくなります。
6. 動画編集ソフトにWAVを読み込み、タイムラインの音声トラックへ置きます。

テキストの一部が選択されていると、その部分だけが再生・書き出しの対象になります。全文を書き出すときは、選択を解除してください。

## 原稿を保存する

練習用の文章を「原稿/サンプル.txt」などに自分で保存し、アプリの File → Open で開きます。自分の原稿は別名のUTF-8テキスト（改行LF）で保存してください。

注意：アプリで開いたテキストファイルは、編集中にも内容が更新されます。原本を残したい場合は、コピーを開いて編集します。File → Save は原稿の保存、Wav Save は音声の保存です。

長い動画は、段落やセリフごとに分けると修正が容易です。

```text
001_導入.txt → 001_導入.wav
002_説明.txt → 002_説明.wav
003_締め.txt → 003_締め.wav
```

## 声と速さを調整する

まずは「話速100・音量100・音程100」を基準にします。声を変えて試聴し、その後で一項目ずつ調整してください。

| 項目 | 使い方 |
|---|---|
| 声種 | AquesTalk1・2・10と、それぞれの声を選ぶ |
| 話速 | 小さくすると遅く、大きくすると速くなる。まず90〜110程度で試す |
| 音量 | 100を基準にする。音割れがあれば下げる |
| 棒読み | 抑揚を抑えたいときに使う |
| 音程 | 高低を変える。再生速度にも影響するので試聴する |
| 高さ・アクセント・声質 | AquesTalk10用。AquesTalk1の調整には使わない |

気に入った設定は **Add** で名前を付けて保存します。既存の自作プリセットを更新するときは **Set** を使います。

## 動画向けのWAV設定

「その他 → 環境設定」で、サンプリング周波数を一定にし、**48kHz** を選びます。リサンプリングは **Sinc** を基準にします。

出力先の例（リポジトリからの相対パス）：

```text
examples/nhk-chairman/音声/v2
```

自動ファイル名を無効にすると、保存時に自分でファイル名を決められます。先頭が欠ける場合は先頭の無音区間を少し増やします。セリフ間の長い間は、編集ソフトのタイムラインで調整します。

48kHzへの変換は編集用の形式をそろえる処理です。元の音声エンジンの音質そのものが高精細になるわけではありません。

## 読み間違いを直す

1. 単発なら、その語だけひらがな・カタカナに置き換えます。
2. 数字や英字が不自然なら、読みたい日本語に書き換えます。例：「Mac」→「マック」。
3. 区切りがおかしい場合は、読点「、」や句点「。」を追加します。
4. 繰り返し出る名前は「その他 → ユーザ辞書設定」で表記・読み・品詞を登録し、保存します。
5. 固有名詞は必ず試聴して確認します。

音声用原稿と画面に出す字幕は、別に管理して構いません。読み上げは仮名、字幕は本来の漢字という運用ができます。

## 動画編集ソフトで使う

WAVをプロジェクトの素材として読み込み、音声トラックへ置きます。映像に合わせて配置し、必要に応じて前後の余白を切ります。BGMを重ねる場合は、声が聞き取れる音量までBGMを下げて確認します。

音声を修正するときは、元のテキストを直して書き出し直します。編集ソフトで読み込んだ素材を差し替えるか、別名で保存して入れ替えてください。

## ターミナルやCodexから生成する

下記は動作確認済みの呼び出し方です。GUIを開かず、テキストファイルからWAVを作れます。`-P` はプリセット名、`-F` はUTF-8原稿、`-W` は出力先です。既存のWAVを上書きしないよう、新しい名前を指定してください。

```bash
/Applications/AquesTalkPlayer.app/Contents/MacOS/AquesTalkPlayer \
  -P "れいむ" \
  -F "原稿/サンプル.txt" \
  -W "examples/nhk-chairman/音声/v2/新しい音声.wav"
```

`れいむ` を `まりさ` に変えると声が切り替わります。出力フォルダは事前に作成してください。プリセット名を省略すると画面の直前の設定が使われるため、毎回指定すると安定します。

Codexへの依頼例：「この原稿を、インストール済みのAquesTalkPlayerで、れいむの48kHz WAVにしてください。セリフごとに分けて音声フォルダへ保存してください。」

## 困ったとき

| 症状 | 確認すること |
|---|---|
| 文章の一部しか保存されない | テキストの選択範囲を解除する |
| 声が違う | プリセットと声種を確認する |
| 音が割れる | アプリの音量を100以下に下げる |
| 読めない文字・長文のエラー | 絵文字などを外し、文を短く分ける |
| 保存したファイルが見つからない | 環境設定のWAV出力先と自動ファイル名設定を確認する |
| 原稿の文字化け | UTF-8のプレーンテキストとして保存する |
| GUIで再生できるが音が聞こえない | Macの出力機器・音量とミュートを確認する |
