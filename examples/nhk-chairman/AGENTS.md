# NHK会長編（AI どうしの共有の決まり）

Codex も Claude Code もこのファイルを読む（Claude Code は CLAUDE.md から読み込む）。

## 分担のしくみ（統括＝Claude Code）

| ファイル | 書く人 | 中身 |
|---|---|---|
| `tasks.json` | 統括だけ | 全作業の一覧・担当・状態・前提・受け入れ条件 |
| `tasks/<ID>_<名前>/brief.md` | 統括 | 目的・入力・やること・出力先・受け入れ条件・報告の書式 |
| `tasks/<ID>_<名前>/報告.md` | 担当の AI | 結果。1行目は `状態：完了`／`途中`／`詰まり` |
| `作業ログ.md` | 統括（と看板ボード） | 何が起きたかの記録 |

担当の AI は brief.md を読んで実行し、報告.md を書くだけ。tasks.json と 作業ログ.md は触らない。brief の「出力」以外に書かない。上書きしない（版を上げる）。

## 公開前提の決まり

- 画面に出す素材は、自作の絵・自作の図・法令の条文だけ。番組映像・公式ロゴ・報道写真は使わない。人物の公式写真をそのまま使ったりトレースしたりしない
- API キー・個人情報・`.env` はこのフォルダに置かない

## 絵の仕様

- 人物：360×640・透過 PNG・べた塗り。頭の上端の中央を (180, 97) にそろえ、表情の差分の間で顔の位置を変えない
- 建物・背景：透過 PNG。横長でよい（縦動画では真ん中の帯に置く）
