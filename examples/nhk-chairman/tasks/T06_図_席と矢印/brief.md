# T06 図：12の席・3段の矢印・視聴者の家

- 担当：Codex CLI（ChatGPT契約内）
- 工程：素材
- 前提の作業：T02（台本 v1）

## 目的

台本の「自作の図」の表にある図を、透過 PNG の部品として作る（動きは後の Premiere 化で付けるので、ここでは静止画の差分でよい）。

## 入力（読むもの）

- `台本_v1_NHK会長編.md`
- `AGENTS.md`

## やること

1. Python（Pillow）で描き、描くスクリプトも 図/v1/make_figures.py として残す（作り直せるように）。
2. 12の席：4×3に並んだ席（人の形の簡単なアイコン）。1080×800・透過。差分は「全部暗い」「点灯1〜9（1つずつ増える）」「9つ目だけ消えた（8つ点灯）」の11枚。点灯は黄 #FFE600、暗い席はグレー。
3. 3段の矢印：上から「顔のない人形（総理大臣）」→「12の席を縮めた形」→「空の枠（会長の絵を後で重ねる場所）」を下向きの矢印でつなぐ。1080×1300・透過。段ごとに別の PNG にもする（1段ずつ出すため）。
4. 視聴者の家：小さな家の形 400×400・透過。点線の矢印（家から上へ伸びる）と赤 #F52222 の✗を別の PNG にする。
5. 図には文字を入れない（文字はテロップで出す）。実在の人物に似せない。
6. 全部を並べた確認用の 図/v1/一覧.png を作る。

## 出力（書いてよい場所はここだけ）

- `図/v1/`
- `tasks/T06_図_席と矢印/報告.md`

## 受け入れ条件（統括が studio.py check で点検する）

- `図/v1/*.png` が PNG（任意の大きさ・透過）で6枚以上
- `図/v1/一覧.png` がある
- 報告.md の「状態：完了」

## 守ること

- 出力の場所以外のファイルは書き換えない。すでにあるファイルは上書きしない（直すときは版を上げる）。
- tasks.json と 作業ログ.md は統括だけが書く。触らない。
- 課金のある API は使わない（必要なら報告の申し送りに書いて止まる）。
- 公開前提：画面に出す素材は、自作の絵・自作の図・法令の条文だけ。番組映像・公式ロゴ・報道写真は使わない。
- 確認や質問で止まらず、判断できることは判断して最後まで進める。判断できないことは申し送りに書く。

## 報告の書式（報告.md に、この形で書く）

```
状態：完了｜途中｜詰まり（どれか1つ）
やったこと：（箇条書き）
成果物：（パス。brief の「出力」と同じ場所）
受け入れ条件：（1つずつ、満たしたか）
申し送り：（統括やほかの担当に頼むこと・気づいたこと。なければ「なし」）
```
