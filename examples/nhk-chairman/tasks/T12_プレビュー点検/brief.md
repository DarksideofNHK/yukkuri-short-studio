# T12 プレビューの点検（別モデル）

- 担当：Codex CLI（ChatGPT契約内）
- 工程：検収
- 前提の作業：T11（Premiere XML のビルド）

## 目的

確認用の並べ画像（45フレームおき）を見て、テロップと顔・図の重なり、読めない文字、下1/3の出典、台本との食い違い、事実の言い過ぎを、組み立てた Claude とは別の目で指摘する。

## 入力（読むもの）

- `premiere/v1/確認_見た目_v1_全体.png`
- `premiere/v1/timeline.json`
- `台本_v2b_NHK会長編.md`
- `AGENTS.md`
- `~/.claude/skills/premiere-short-xml/references/design_rules.md`

## やること

1. premiere/v1/確認_見た目_v1_全体.png を開いて、コマごとに見る（各コマの左上に フレーム数と時刻）。
2. design_rules.md の配置の決まり（下1/3は出典、テロップは真ん中が基本で顔を見せる拍だけ下げる、顔にテロップを意味なく重ねない）と照らす。
3. テロップの文字が台本 v2b のナレーションと食い違っていないか、事実を言い過ぎていないかを見る。
4. 見つけたことを表（フレーム｜何が問題か｜直す案｜重さ：必ず直す／直した方がよい／好み）にして報告に入れる。ファイルは書かない。

## 出力（書いてよい場所はここだけ）

- `tasks/T12_プレビュー点検/報告.md`

## 受け入れ条件（統括が studio.py check で点検する）

- 報告.md の「状態：完了」

## 守ること

- 出力の場所以外のファイルは書き換えない。すでにあるファイルは上書きしない（直すときは版を上げる）。
- tasks.json と 作業ログ.md は統括だけが書く。触らない。
- 課金のある API は使わない（必要なら報告の申し送りに書いて止まる）。
- 公開前提：画面に出す素材は、自作の絵・自作の図・法令の条文だけ。番組映像・公式ロゴ・報道写真は使わない。
- 確認や質問で止まらず、判断できることは判断して最後まで進める。判断できないことは申し送りに書く。

## 報告の書式（報告.md に、この形で書く）

```
状態：完了｜途中｜詰まり（どれか1つ）
やったこと：（箇条書き）
成果物：（パス。brief の「出力」と同じ場所）
受け入れ条件：（1つずつ、満たしたか）
申し送り：（統括やほかの担当に頼むこと・気づいたこと。なければ「なし」）
```
