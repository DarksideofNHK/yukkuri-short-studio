# T03 台本のファクトチェック（別モデル）

- 担当：Codex CLI（ChatGPT契約内）
- 工程：台本
- 前提の作業：T02（台本 v1）

## 目的

台本の事実の誤りと、耳で聞いて誤解を招く言い方を、台本を書いた Claude とは別のモデルの目で見つける。

## 入力（読むもの）

- `台本_v1_NHK会長編.md`
- `research/ファクト表.md`
- `research/一次資料/放送法_第30・31・52条.md`
- `research/一次資料/経営委員会_第1483回議事録_抜粋.md`

## やること

1. 台本のナレーション（``` の中の14行）と「テロップの要点」の表・注記から、事実を言っている箇所をすべて拾う。
2. それぞれを research/一次資料/ の原文と照らして「合っている／言い過ぎ／違う／根拠なし」のどれかで判定する。報道だけが根拠のもの（ファクト表の「補強」）は、そうと分かるように書く。
3. 耳で聞いて誤解されそうな言い方（例：総理大臣が一人で選ぶように聞こえる、視聴者が何もできないように聞こえる）を指摘し、直す案を1つずつ出す。
4. 結果は表（行番号｜台本の言葉｜判定｜根拠の原文｜直す案）にして、報告の「やったこと」に入れる。ファイルは書かない（読み取りだけ）。

## 出力（書いてよい場所はここだけ）

- `tasks/T03_台本のファクトチェック/報告.md`

## 受け入れ条件（統括が studio.py check で点検する）

- 報告.md の「状態：完了」
- `tasks/T03_台本のファクトチェック/報告.md` に「合っている|言い過ぎ|違う|根拠なし」が6回以上

## 守ること

- 出力の場所以外のファイルは書き換えない。すでにあるファイルは上書きしない（直すときは版を上げる）。
- tasks.json と 作業ログ.md は統括だけが書く。触らない。
- 課金のある API は使わない（必要なら報告の申し送りに書いて止まる）。
- 公開前提：画面に出す素材は、自作の絵・自作の図・法令の条文だけ。番組映像・公式ロゴ・報道写真は使わない。
- 確認や質問で止まらず、判断できることは判断して最後まで進める。判断できないことは申し送りに書く。

## 報告の書式（報告.md に、この形で書く）

```
状態：完了｜途中｜詰まり（どれか1つ）
やったこと：（箇条書き）
成果物：（パス。brief の「出力」と同じ場所）
受け入れ条件：（1つずつ、満たしたか）
申し送り：（統括やほかの担当に頼むこと・気づいたこと。なければ「なし」）
```
