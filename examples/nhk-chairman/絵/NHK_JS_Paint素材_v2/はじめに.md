# 井上会長 似顔絵 v2

前回より本人の顔立ちを優先し、髪の分け目と横への流れ、小さめの細い眼鏡、重いまぶた、鼻の幅、厚い唇、頬・顎の形をJS Paintで修正しました。
口開きと汗つき困り顔の2点。元サイズは360×640、透過PNGは1080×1920（最近傍補間3倍）。既存版と同じ位置で差し替え可能です。
放送センターはv1と同一の素材を同梱。旧版はそのまま残しています。

本人らしさは目視確認で、ユーザー確認前です。写真そのものは配布素材に含めていません。
描画・背景透過はJS Paint。動画用拡大と比較画像の配置はPillowを使用。
